# SMG website

Source for smgindustriesltd.com (Sammas Multiconcept Global Industries Ltd).

## Files
- `index.html`: the whole page. Text, prices, contact details and styles are all in this one file.
- `assets/`: images and the hero video (`hero.mp4`). Replace a file with one of the same name to change a picture.
- `CNAME`: tells GitHub Pages the domain is smgindustriesltd.com. Do not delete.
- `.nojekyll`: keeps GitHub from reformatting the site. Do not delete.

## To edit the text
1. Open `index.html` on GitHub and click the pencil icon (Edit).
2. Press Ctrl+F to find the words you want to change. Change them.
3. Click "Commit changes". The live site updates in about a minute.

## To change a picture
Open the `assets` folder, click "Add file", then "Upload files". Use the same file name to replace one.

## Contact details to update when the domain email is live
The Gmail address appears several times in `index.html` (search for `gmail.com`).
